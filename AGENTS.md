# Project guidance

This project aims to build the financial research assistant described in [plan.md](plan.md). Read the plan for technical requirements and project context when working on the project.

If a technical detail needed for the task is missing from the plan or requirements conflict, ask the user directly for clarification.

## UI rules

- Cut taglines, helper text and secondary labels. If a screen needs them to make sense, fix the layout.
- Make the best decision that will elevate all three: the user experience (UX), developer experience (DX), and agent experience (AX) always, without breaking anything.

## Code rules 
- Keep the code modular. Do not write everything in one file. if something can be modular make it.
